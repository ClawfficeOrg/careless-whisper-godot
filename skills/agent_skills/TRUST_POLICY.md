# Agent Skills Bundle — Trust Policy

This document defines the trust policy for agent skills generated by Zoid.
It applies to all skill files in the `skills/` directory of any project
generated with the `agent-skills` feature.

## Scope

This policy covers:

- All Markdown skill files generated by the `agent-skills` feature template.
- Any modifications to those files made locally.
- Any future skills contributed to this repository via pull request.

## What These Skills Are

Skills are plain Markdown documents that describe how a coding agent should
perform a specific task. They contain:

- Step-by-step instructions for humans and agents.
- Pre-approved shell commands in fenced code blocks.
- Constraints and forbidden patterns.

Skills are **not** executable scripts. They do not run automatically.

## Generation Guarantee

Skills generated by Zoid:

1. **Are generated locally** from templates stored in `templates/features/agent_skills/`.
2. **Are never fetched from the internet** at generation time.
3. **Contain no binary attachments** — plain UTF-8 Markdown only.
4. **Are written to a known output path** inside the generated project root.
5. **Do not escape the project root** — path traversal is prevented by the renderer.

## Allowed Network Behaviour

Skills may **instruct** an agent to read public URLs for information gathering
(e.g., fetching GPUI docs from docs.rs). This is subject to the following
restrictions:

- The URL must be explicitly listed in the skill text.
- The content may only be **read** — never downloaded and executed.
- No credentials or project source code may be transmitted.
- All network access must be logged in `docs/memory.md` with the date and URL.

## Shell Command Policy

An agent following a skill may only execute commands in the `## Safe Shell Commands`
section of that skill, plus the globally permitted commands listed in
`NOTES-security.md`.

Forbidden patterns (must never appear in any skill command):

- `curl … | sh` / `wget … | sh` — remote code execution via pipe
- `eval $(…)` — dynamic command construction
- `bash -c "…$(…)…"` — nested shell substitution
- `sudo` without explicit user acknowledgement
- `rm -rf /` or `rm -rf ~` — destructive filesystem operations
- `cargo install` from within the generated project without user request
- `${var@P}` or `${!var}` — shell parameter transformation / indirect expansion

## Modification Policy

- Skill files may be edited locally to suit your project.
- Any edit that adds a new shell command must be reviewed by a human before use.
- Changes submitted to the Zoid repository require a security review comment
  from a project owner before merge.
- Auto-generated updates from `zoid` are safe to merge after CI passes.

## Non-Warranty

These skills are provided as development aids. The project authors make no
warranty that following a skill will produce correct results in every
environment. Users are responsible for reviewing skill instructions before
activating them in an automated agent session.

## Reporting

Security concerns about any skill file should be reported as a GitHub issue:

```
https://github.com/CompewterTutor/Zoid/issues
```

Include the skill file name, the concerning content, and a description of the
potential risk.
