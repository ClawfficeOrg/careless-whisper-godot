# Careless Whisper - Godot Speech Recognition

A Godot 4.6 speech recognition addon powered by [whisper.cpp](https://github.com/ggerganov/whisper.cpp) via GDExtension.

## Overview

Careless Whisper brings real-time speech-to-text capabilities to Godot games and applications. It leverages the high-performance [whisper.cpp](https://github.com/ggerganov/whisper.cpp) library through a custom GDExtension.

## Dependencies

This project depends on:
- **[godot-whisper-cpp-node](https://github.com/ClawfficeOrg/whisper.cpp/tree/godot-whisper-cpp-node)** - GDExtension bindings for whisper.cpp (branch in ClawfficeOrg/whisper.cpp fork)

## Installation

1. Clone this repository
2. Build the GDExtension from the [godot-whisper-cpp-node](https://github.com/ClawfficeOrg/whisper.cpp/tree/godot-whisper-cpp-node) branch
3. Place the compiled extension in the `addons/` directory
4. Enable the addon in Project Settings
